# Security & Fraud Prevention

## Common Fraud Signs
- A call from "bank security" asking for your SMS code
- Message about "account blocked" with a link to "unblock"
- Request to install a "remote assistance" app
- Offer to transfer money to a "safe account"

## What To Do If You're a Fraud Victim
1. Block your card immediately
2. Call the bank: 1-800-NEO-BANK
3. File a police report
4. Submit a fraud claim within 24 hours

## Fraud Insurance
- Coverage: $99/year
- Covers: Unauthorized transactions up to $50,000
- Does NOT cover: Transactions confirmed with your PIN or SMS code

## Two-Factor Authentication
- SMS confirmation for online purchases (3D Secure)
- Push notifications for every transaction
- Biometric login in the mobile app
