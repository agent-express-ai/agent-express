# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in agent-express, please report it responsibly.

**Email**: security@agent-express.ai

**Or**: Use [GitHub Security Advisories](https://github.com/agent-express-ai/agent-express/security/advisories/new)

Please include:
- Description of the vulnerability
- Steps to reproduce
- Affected versions
- Potential impact

**Do not** open a public issue for security vulnerabilities.

## Response Timeline

| Step | Timeframe |
|------|-----------|
| Acknowledgment | 48 hours |
| Initial assessment | 7 days |
| Fix and coordinated disclosure | 30 days |

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | Yes       |

## Scope

This policy covers the framework code in `src/`. For vulnerabilities in third-party dependencies, please report them to their respective maintainers.

## Recognition

We credit security reporters in release notes (with your permission).
